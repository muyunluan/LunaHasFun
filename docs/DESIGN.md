# Visual & UX Guidelines

## Core Philosophy
The interface must be highly engaging, accessible, and distraction-free for 7-8 year old children. Touch targets must be large and forgiving.

## Color Palette
*   **Primary:** Sky Blue (`#4DB6AC`) - Calming, used for main backgrounds.
*   **Secondary:** Sunflower Yellow (`#FFF176`) - Used for primary action buttons (e.g., "Check Answer").
*   **Success:** Mint Green (`#81C784`) - Used for correct answer feedback.
*   **Error/Retry:** Soft Orange (`#FFB74D`) - Avoid harsh reds. Used to encourage a retry.

## Typography
*   **Font Family:** Use a highly legible, rounded sans-serif font (e.g., 'Quicksand' or 'Comic Neue' via Google Fonts).
*   **Sizing:**
    *   Numbers/Equations: Extremely large (e.g., `64sp`).
    *   Instructions: Large and readable (e.g., `24sp`).

## Component Styling
*   **Buttons:** Heavy corner radius (`RoundedCornerShape(16.dp)`), slight elevation for depth.
*   **Coin Images:** High-resolution, realistic PNGs of pennies, nickels, dimes, and quarters with transparent backgrounds.
