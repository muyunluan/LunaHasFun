# Project Overview

## Goal
To create a safe, engaging, and ad-free educational Android tablet/phone application that helps 2nd-grade students practice core curriculum concepts.

## Target Audience
Children aged 7-8 years old (2nd Grade). The app requires minimal reading and relies heavily on visual cues, numbers, and immediate positive feedback.

## Key Features
1.  **Math Practice:** Randomly generated 2-digit addition and subtraction problems. Ensures the top number is larger in subtraction to avoid negative numbers.
2.  **Money Counting:** Displays a visual collection of coins. The child must calculate the total cent value.
3.  **Calendar Logic:** Teaches day and date awareness. Asks questions like "What is today?" or "If today is Tuesday, the 7th, what date is it in 7 days?".
